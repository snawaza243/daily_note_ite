👉 RAM kya hoti hai? (Temporary Memory - Beginner Friendly Guide)

🔹 Real Life Example (Hindi me)

Maan lo tum ek table par kaam kar rahe ho 📝. Tumhare paas ek chhota box hai jisme tum daily kaam ke liye papers rakhte ho.

  • Table par jo papers kaam ke liye rakhte ho → temporary memory
  • Jab kaam khatam → papers hata dete ho

Bilkul isi tarah RAM (Random Access Memory) temporary memory ka kaam karti hai computer me.

🔹 RAM ki Definition

RAM ka full form hai Random Access Memory. Ye computer ki temporary memory hoti hai jo currently running programs aur data ko store karti hai.

👉 Simple words me: RAM = Computer ki short-term memory

🔹 RAM ka kaam kya hota hai?

  • Currently running programs aur apps ko store karna
  • CPU ko fast access provide karna
  • Computer ko fast aur responsive banana
  • Temporary data ko hold karna jab tak power on hai

👉 RAM me data sirf tab tak rehta hai jab tak computer on hai. Power off → data erase.

🔹 RAM aur Hard Disk me difference

RAM Hard Disk / SSD
Temporary memory Permanent memory
Fast access Slower than RAM
Volatile (power off → data lost) Non-volatile (data saved even after power off)
Used for running programs Used for storage of files

🔹 RAM kaise kaam karti hai?

CPU ke liye RAM ek fast storage ka kaam karti hai. Jab program run hota hai:

  • Program ke instructions RAM me load hote hain
  • CPU instructions ko read karta hai aur process karta hai
  • Jab computer band hota hai → RAM ka data erase ho jata hai

🔹 RAM ke Types

  • DRAM (Dynamic RAM): Common type, refresh karna padta hai
  • SRAM (Static RAM): Fast type, refresh nahi karna padta
  • DDR RAM: Double Data Rate, modern computers me use hota hai

👉 Jitni jyada RAM, utna zyada programs simultaneously run kar sakte ho.

🔹 Real Life Use Case

Maan lo tum YouTube aur Chrome ek saath chalate ho:

  • Chrome ka data RAM me load hota hai
  • YouTube ka video RAM me process hota hai
  • CPU dono programs se data fast access karta hai

👉 RAM ki wajah se computer lag-free aur fast feel hota hai.

🔹 Important Points

  • RAM temporary memory hai
  • Power off → RAM me data erase
  • CPU ke liye fast access provide karti hai
  • Jitni jyada RAM → better multitasking

🔹 Short Summary

✔ RAM = Random Access Memory (temporary)
✔ Current programs aur data store karti hai
✔ Volatile memory, power off → data lost
✔ Jitni zyada RAM, utna fast aur multitasking-friendly computer
