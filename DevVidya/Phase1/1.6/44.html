👉 URL kya hota hai? (Beginner Friendly Guide)

🔹 Real Life Example (Hindi me)

Maan lo tum ek library me book lene gaye aur tumhe exact book ka shelf number pata hai. Tum directly us shelf par jaa ke book le sakte ho. Bilkul isi tarah, URL website ya web page ka exact address hota hai jo browser ko batata hai ki kaunse server se data lena hai.

🔹 Definition

URL ka full form hai Uniform Resource Locator. Ye Internet par kisi website, page, image, video ya resource ka unique address hota hai.

👉 Simple words me: URL = web resource ka exact location jisse browser access karke content show karta hai.

🔹 URL ke Components

  • Protocol: Website access ka method, jaise http, https, ftp
  • Domain Name: Website ka main address, jaise www.example.com
  • Port: Optional, server ka specific port number
  • Path: Resource ya page location, jaise /about-us
  • Query Parameters: Optional, data pass karne ke liye, jaise ?id=123
  • Fragment: Optional, page ke specific section ko point karta hai, jaise #contact

🔹 Types of URLs

  • Absolute URL: Full path including domain and protocol, e.g., https://www.example.com/page1
  • Relative URL: Current website ke context me path, e.g., /page1
  • Dynamic URL: Data-driven pages with query parameters, e.g., https://www.example.com/page?id=101
  • Static URL: Simple, fixed pages, e.g., https://www.example.com/about

🔹 How URL Works

  1. User browser me URL type karta hai
  2. Browser DNS se IP address resolve karta hai
  3. Browser server ko request bhejta hai
  4. Server requested resource ke data ko browser ko send karta hai
  5. Browser resource ko render karta hai aur user ko display hota hai

🔹 Advantages of Understanding URL

  • Directly correct page access karna easy
  • Website structure samajhne me help
  • SEO aur web development me kaam aata hai
  • Data pass aur dynamic pages ka understanding
  • Security ke liye HTTPS aur correct domains identify karna
