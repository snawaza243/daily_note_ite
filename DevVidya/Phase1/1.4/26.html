👉 File ka Extension kya hota hai? (.jpg, .pdf, .exe) (Detailed Beginner Friendly Guide)

🔹 Real Life Example (Hindi me)

Maan lo tumhare ghar me ek cupboard hai 🗄️ aur usme alag-alag files rakhi hain: school assignments, photos, software CDs, bills. Har file pe ek label laga hua hai jaise “Math Assignment”, “Birthday Photo”, “Setup CD” – ye label bata raha hai file ka type. Bilkul isi tarah, computer me **file extension** file ke type ko identify karta hai.

🔹 File Extension ki Definition

File extension ek chhota suffix hai jo file ke naam ke end me hota hai, usually 2–4 characters ka, aur ek dot (.) ke saath likha jata hai. Ye file ke type aur format ko identify karta hai, aur computer ko batata hai ki kaunsa program is file ko open kare.

👉 Simple words me: File Extension = ek chhota tag jo batata hai ki file ka type kya hai aur kaunse software se open hogi.

🔹 Common File Extensions aur Examples

1. Text Files

  • .txt → Simple text file
  • .doc / .docx → Microsoft Word document
  • .pdf → Portable Document Format (read-only documents)

2. Image Files

  • .jpg / .jpeg → Photos aur images
  • .png → Transparent images
  • .gif → Animated images

3. Audio Files

  • .mp3 → Music files
  • .wav → High quality sound files

4. Video Files

  • .mp4 → Movies aur videos
  • .avi → Video files

5. Executable Files

  • .exe → Windows programs
  • .bat → Batch files (commands)

6. Compressed Files

  • .zip → Compressed folder
  • .rar → Compressed archive

🔹 Importance of File Extensions

  • Identify karna ki file ka type kya hai
  • Computer ko batata hai kaunsa program open kare
  • File organize aur search me helpful
  • Security aur virus detection me help karta hai (exe aur bat files suspicious ho sakte hain)
  • Compatibility ensure karta hai (software ke sath)

🔹 How to View File Extension?

  • Windows me: File Explorer → View → File name extensions check karo
  • Mac me: Finder → Preferences → Show all filename extensions
  • Right-click → Properties → Type of file

🔹 Real Life Use Cases

  • Assignment submit karna → .docx ya .pdf
  • Photos share karna → .jpg ya .png
  • Music sunna → .mp3
  • Movie dekhna → .mp4
  • Software install karna → .exe
  • Multiple files send karna → .zip / .rar
