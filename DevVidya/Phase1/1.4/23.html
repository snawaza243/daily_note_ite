👉 File kya hoti hai? (Detailed Beginner Friendly Guide)

🔹 Real Life Example (Hindi me)

Maan lo tumhare ghar me ek cupboard hai 🗄️. Us cupboard me alag-alag important papers rakhe hain – school reports, bills, letters, etc. Bilkul isi tarah computer me **file** ek digital container hai jo data ko store karta hai, jaise ki text, images, videos ya software instructions.

🔹 File ki Definition

Computer me file ek collection of data ka digital container hai jo ek specific format me save hota hai. File me information organize hoti hai aur ek unique name ke sath computer storage me rakhi ja sakti hai.

👉 Simple words me: File = ek digital document ya data ka container jo computer me save aur manage kiya ja sakta hai.

🔹 Types of Files

1. Text Files

  • Sirf text data store karte hain
  • Examples: .txt, .doc, .docx

2. Image Files

  • Photos aur images ke liye
  • Examples: .jpg, .png, .gif

3. Audio Files

  • Sound aur music store karte hain
  • Examples: .mp3, .wav

4. Video Files

  • Movies aur videos ke liye
  • Examples: .mp4, .avi, .mov

5. Executable Files

  • Programs run karne ke liye
  • Examples: .exe, .bat

6. Compressed Files

  • Multiple files ko ek file me compress karte hain
  • Examples: .zip, .rar

🔹 File ke Components

  • File Name: Har file ka unique naam
  • File Extension: File ke type ko indicate karta hai (e.g., .txt, .jpg)
  • File Location: Jahan file computer me save hoti hai
  • File Size: File me stored data ka size (KB, MB, GB)

🔹 Importance of Files

  • Data organize karna aur save karna easy banata hai
  • Multiple users aur applications ke liye access provide karta hai
  • Backup aur recovery me helpful hai
  • Security aur privacy maintain karne me madad karta hai
  • Efficient storage aur retrieval possible banata hai

🔹 Real Life Use Cases

  • School aur college assignments → .doc, .pdf
  • Photos aur images → .jpg, .png
  • Music aur songs → .mp3, .wav
  • Videos aur movies → .mp4, .avi
  • Software aur programs → .exe, .bat
  • Compressed data transfer → .zip, .rar

🔹 How to Identify a File?

  • File Name aur Extension check kare → example: assignment.docx
  • File Icon dekhkar type identify kar sakte hain
  • Right-click → Properties → Type of File
