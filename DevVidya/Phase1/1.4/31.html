👉 Rename kya hota hai? (Detailed Beginner Friendly Guide)

🔹 Real Life Example (Hindi me)

Maan lo tumhare ghar me ek cupboard hai 🗄️ jisme kai alag-alag boxes hain. Ek box pe purana naam likha hai, lekin ab tum us box ko nayi cheez store karne ke liye rename karna chahte ho. Bilkul isi tarah, computer me **file ya folder rename karna** uska naam change karna hota hai.

🔹 Definition

Rename ka matlab hai kisi file, folder ya document ka purana naam badal kar naya naam dena. Isse hum files ko organize kar sakte hain aur easily identify kar sakte hain.

👉 Simple words me: Rename = purani file ya folder ka naam change karna taki wo clearly identifiable ho.

🔹 Rename Karne ke Methods (Windows)

  1. Right-Click Method:
    • File ya folder pe right-click kare
    • “Rename” option select kare
    • Naya name type kare aur Enter press kare
  2. Keyboard Shortcut:
    • File select kare
    • Press F2 → Naya name type kare → Enter press kare
  3. Menu Method:
    • Home tab (Explorer me) → Rename option select kare → Naya name type kare

🔹 Rename Karne ke Methods (Mac)

  • File/Folder select kare → Right-click → Rename
  • File/Folder select kare → Press Return key → Naya name type kare → Enter
  • Multiple files rename karne ke liye → Finder → Edit → Rename

🔹 Important Tips While Renaming

  • File extension ko accidentally change na kare (.txt, .jpg, .pdf)
  • Meaningful aur short names rakhe taki easily identify ho
  • Special characters avoid kare (/, \, *, ?, <, >)
  • Batch rename feature ka use karke multiple files ek saath rename kare
  • Folder rename karte waqt internal files safe rehte hain

🔹 Real Life Use Cases

  • School assignments → subject_name.docx
  • Photos → event_date_location.jpg
  • Project files → project_version1.docx → project_version2.docx
  • Music files → song_artist_name.mp3
  • Folders → Work_Projects, Personal_Documents, Backup
